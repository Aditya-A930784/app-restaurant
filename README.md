# About

The Restaurant Management System is a full-stack web application developed to digitize restaurant operations and provide customers with a seamless online food ordering experience.

The system enables customers to browse restaurants, explore menus, place food orders, manage their profiles, and track order status. Administrators can efficiently manage restaurants, menu items, orders, customers, and analytics through an intuitive dashboard.
